# Как править этот проект

Книга, интерактив и Go-тренажёр живут в одном репозитории и связаны реестрами,
поэтому «поправил главу» иногда означает «поправь ещё три места». Ниже — что
именно и как это проверяется автоматически.

## Перед коммитом

```bash
make check      # ровно то, что гоняет CI: эталоны, листинги, книга, ссылки, реестры
```

Плюс jsdom-смоуки виджетов (в CI они всегда, локально требуют `npm i --no-save jsdom`,
без него мягко пропускаются):

```bash
node scripts/viz-render-check.js
node scripts/challenge-engine-check.js
node scripts/progress-render-check.js
```

## Добавить пакет в тренажёр

Три файла с одинаковыми сигнатурами (подробно — в [`exercises/README.md`](exercises/README.md)):

| Файл | Тег сборки | Что внутри |
|---|---|---|
| `<pkg>/<pkg>.go` | `//go:build !solution` | заготовки с `panic("TODO: ...")` |
| `<pkg>/<pkg>_solution.go` | `//go:build solution` | эталон |
| `<pkg>/<pkg>_test.go` | нет | табличные тесты — общая спецификация обоих |

Тест-файл без тега — значит, сигнатуры заготовки и эталона обязаны совпадать
дословно, иначе не скомпилируется. CI проверяет и обратное: заготовка НЕ должна
проходить тесты (иначе решение утекло в файл-заготовку).

Дальше: строка в таблицу `exercises/README.md` и счётчик пакетов в `CLAUDE.md`
(`scripts/check-registries.js` не даст забыть).

## Добавить главу

1. Файл `src/<chapter>.md` и строка в `src/SUMMARY.md`.
2. Строка в `GROUPS` (`assets/progress.js`) — иначе главу не увидит трекер прогресса.
3. Виджеты по вкусу: `algo-viz` (визуализация — нужен конфиг `DASH`/`CODE` в
   `assets/algo-viz.js`), `algo-challenge` (задача в тексте), `algo-runner`
   (`data-pkg` существующего пакета).
4. Чтобы в главе работала кнопка «🎞 Визуализировать», функция должна быть
   разрешена в `traceTargets` (`exercises/cmd/runner/trace.go`).

Пункты 2 и 4 сверяет `scripts/check-registries.js`, виджеты — `check-viz.js` и
`check-challenges.js`.

## Go-листинги в главах

Каждый блок ```go разбирается через `go/parser` (`cmd/checksnippets`). Листинг может
быть декларациями, фрагментом (тело цикла) или смешанным — все три формы законны.
Настоящий псевдокод помечается строкой `<!-- snippet:pseudo -->` прямо перед
открывающим ```go: в собранной книге это невидимый HTML-комментарий. Метку на
листинге, который на самом деле разбирается, CI тоже считает ошибкой.

## Стиль

- Язык контента и коммитов — русский; код примеров — Go.
- Комментарии объясняют **почему**, а не **что**.
- Правка держится идиом окружающего кода: те же имена, та же плотность комментариев.

# Алгоритмы и структуры данных: от фундамента к синтезу

Учебник-тренажёр по алгоритмам и структурам данных для инженера, пишущего на Go.
Начинался как конспект «25 шаблонов для собеседований», вырос в полный курс:
50+ глав в восьми группах — от Big-O, инвариантов и дискретной математики до
деревьев отрезков, вероятностных структур, потоков в сетях и разборов того, как
эти же структуры живут в Postgres, Redis, ядре Linux и рантайме Go.

Цель — не зазубрить шаблоны к собеседованию, а **понимать, почему алгоритм
корректен и сколько он стоит в продакшене**: у глав есть разделы «Почему это
корректно» (инварианты и доказательства) и «Цена на практике» (аллокации, кэш,
бенчмарки, pprof).

- **Читать онлайн**: <https://fazletdinov.github.io/algorithms-book/> (деплой из `main` через CI)
- **Локально**: `mdbook serve` → <http://localhost:3000>

## Три слоя

1. **Книга** ([src/](src/)) — теория: полное оглавление в [src/SUMMARY.md](src/SUMMARY.md).
2. **Интерактив** ([assets/](assets/)) — 130+ пошаговых SVG-визуализаций, 650+
   встроенных в главы задач (предскажи ответ / выбери вариант / восстанови
   порядок), [квиз распознавания шаблонов](src/quiz.md) и трекер прогресса —
   всё на vanilla JS, без зависимостей.
3. **Go-тренажёр** ([exercises/](exercises/)) — рабочий Go-модуль: 66 пакетов с
   заготовками функций и тестами. Решение пишешь сам, эталон скрыт за
   build-тегом; тесты — табличные + рандомизированные против наивной модели,
   бенчмарки проверяют асимптотику. Флагманы — «боевые мини-проекты»:
   rate limiter, LRU+TTL-кэш, стриминговая статистика, leaderboard.

## Чему учит

| Группа | Темы |
|--------|------|
| 1. Фундамент | Big-O и амортизация, рекурсия, инварианты и индукция, хеш-таблица, список, дек, сортировки |
| 2. Базовые паттерны | скользящее окно, два указателя, интервалы, циклическая сортировка, бинарный поиск, биты |
| 3. Деревья и кучи | BST, AVL, красно-чёрное, обходы, куча, две кучи, top-K, k-way merge |
| 4. Комбинаторика и графы | subsets, backtracking, BFS/DFS, DSU, топосорт, Дейкстра, Bellman–Ford, A*, MST, SCC и мосты, максимальный поток |
| 5. Оптимизация | жадные, динамическое программирование, P/NP и что делать с трудными задачами |
| 6. Строки и продвинутые структуры | KMP/Rabin–Karp, Trie, дерево отрезков, Фенвик, sparse table, B-дерево, Bloom/HyperLogLog |
| 7. Дискретная математика | комбинаторика счёта, вероятность для инженера, теория чисел, криптография |
| 8. Синтез | комбинации паттернов (LRU, skyline, alien order…), структуры данных в реальных системах |

Дополнительно: Go-рантайм (планировщик, GC, аллокатор), структуры данных в
стандартной библиотеке Go, криптография на практике, память и профилирование.

## Быстрый старт

Требования: **Go 1.24+** (тренажёр) и **[mdBook](https://rust-lang.github.io/mdBook/)** (книга).

```bash
mdbook serve                              # книга на http://localhost:3000

cd exercises
go test ./slidingwindow/                  # твоё решение (красное, пока не написано)
go test -tags solution ./slidingwindow/   # эталон (зелёный)
```

## Решать прямо в книге

Виджет «Реши прямо здесь» в главах гоняет твой код через настоящий `go test`:

```bash
cd exercises
go run ./cmd/runner    # локальный helper-сервер на http://localhost:8080
```

Дальше открой любую главу с тренажёром — стартовый код подтянется сам, кнопка
запускает тесты и показывает результат; для конкурентных пакетов — с `-race`.
Эталон не показывается: решаешь сам, как на LeetCode.

Подробности об устройстве тренажёра (build-теги, список всех пакетов и функций,
методика бенчмарков) — в [`exercises/README.md`](exercises/README.md).

## Что проверяет CI

Тесты и `vet` эталонов, компилируемость заготовок (синхронность сигнатур),
инвариант «заготовки ещё не решены», линт интерактивных задач и визуализаций,
сборку книги и целостность всех внутренних ссылок; из `main` — деплой на
GitHub Pages.

# Алгоритмические шаблоны для решения задач на собеседованиях

Этот репозиторий содержит подробное изучение 14 основных алгоритмических шаблонов, которые помогут решить большинство задач на технических собеседованиях.

## 📚 Содержание

1. [Sliding Window (Скользящее окно)](./sliding-window/) - Операции с подмассивами фиксированного размера
2. [Two Pointers (Два указателя)](./two-pointers/) - Поиск пар элементов в отсортированных массивах
3. [Fast & Slow Pointers (Быстрые и медленные указатели)](./fast-slow-pointers/) - Обнаружение циклов и поиск середины списка
4. [Merge Intervals (Слияние интервалов)](./merge-intervals/) - Работа с перекрывающимися интервалами
5. [Cyclic Sort (Циклическая сортировка)](./cyclic-sort/) - Сортировка массивов с числами от 1 до N
6. [Reverse Linked List (Разворот связанного списка)](./reverse-linked-list/) - Инвертирование списков на месте
7. [Tree BFS (Обход дерева в ширину)](./tree-bfs/) - Поуровневый обход деревьев
8. [Tree DFS (Обход дерева в глубину)](./tree-dfs/) - Рекурсивный обход деревьев
9. [Two Heaps (Две кучи)](./two-heaps/) - Поддержание медианы и разделение данных
10. [Subsets (Подмножества)](./subsets/) - Генерация всех подмножеств множества
11. [Modified Binary Search (Модифицированный бинарный поиск)](./modified-binary-search/) - Вариации бинарного поиска
12. [Top K Elements (Топ K элементов)](./top-k-elements/) - Поиск K наибольших/наименьших элементов
13. [K-way Merge (K-way слияние)](./k-way-merge/) - Слияние K отсортированных массивов
14. [Topological Sort (Топологическая сортировка)](./topological-sort/) - Линейный порядок зависимых элементов

## 🎯 Структура каждого шаблона

Каждый шаблон содержит:
- **README.md** - Подробное теоретическое объяснение с визуализацией
- **go/examples.go** - Примеры реализации на Go
- Ссылки на задачи LeetCode для практики

## 🚀 Как использовать

1. Изучите теорию в README.md каждого шаблона
2. Разберите примеры кода на Go
3. Решите задачи на LeetCode, указанные в каждом разделе
4. Практикуйтесь, применяя шаблоны к новым задачам

- Практикуйтесь на задачах разной сложности
- Понимайте временную и пространственную сложность каждого шаблона

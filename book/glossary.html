Алгоритмические шаблоны для решения задач на собеседованиях

Глоссарий терминов

А

Алгоритм - последовательность шагов для решения задачи.

Асимптотическая сложность - математическое описание производительности алгоритма при росте размера входных данных. Обозначается как O(f(n)).

Анаграмма - слово или фраза, образованная перестановкой букв другого слова или фразы.

Б

Backtracking (Откат) - алгоритмическая техника решения задач путем построения решений пошагово и отката, если решение не подходит.

BFS (Breadth-First Search) - обход графа или дерева в ширину, сначала посещаются все узлы на текущем уровне, затем на следующем.

BST (Binary Search Tree) - бинарное дерево поиска, где для каждого узла все элементы левого поддерева меньше, а правого - больше.

Бинарный поиск - алгоритм поиска элемента в отсортированном массиве путем деления массива пополам.

Бит - минимальная единица информации (0 или 1).

Битовая маска - число, используемое для выбора или модификации определенных битов другого числа (установка, сброс, проверка бита).

Битовые операции - операции над отдельными битами: AND (&), OR (|), XOR (^), сдвиги (<<, >>).

Битовый сдвиг - операция перемещения битов влево (<<) или вправо (>>); эквивалентна умножению/делению на степень двойки.

В

Временная сложность - количество операций, выполняемых алгоритмом в зависимости от размера входных данных.

Вершина (Node) - элемент графа или дерева.

Г

Граф - структура данных, состоящая из вершин и ребер, соединяющих их.

Граничные условия - особые случаи входных данных (пустой массив, один элемент, максимальные значения).

Д

DFS (Depth-First Search) - обход графа или дерева в глубину, сначала полностью исследуется одна ветвь, затем другая.

Двусвязный список - связанный список, где каждый узел имеет ссылки на предыдущий и следующий элементы.

Дерево - связный ациклический граф.

Дубликат - повторяющийся элемент в структуре данных.

И

Инвариант - условие, которое остается истинным на протяжении выполнения алгоритма.

Индекс - позиция элемента в массиве или списке.

Интервал - непрерывный диапазон значений между двумя точками.

Исключающее ИЛИ (XOR) - побитовая операция: результат 1, если биты разные; 0, если одинаковые. Свойства: a^a=0, a^0=a.

К

Куча (Heap) - структура данных, реализующая приоритетную очередь. Минимальная куча: родитель всегда меньше детей. Максимальная куча: родитель всегда больше детей.

Комбинаторика - раздел математики, изучающий комбинации, перестановки и подмножества.

Корень дерева - вершина дерева, не имеющая родителя.

Л

Лист (Leaf) - узел дерева, не имеющий детей.

Линейная сложность - O(n), время выполнения пропорционально размеру входных данных.

Логарифмическая сложность - O(log n), время выполнения растет логарифмически от размера данных.

М

Медиана - значение, разделяющее упорядоченный набор данных пополам.

Мемоизация - техника оптимизации, сохраняющая результаты выполнения функции для повторного использования.

О

Обход (Traversal) - процесс посещения всех узлов структуры данных в определенном порядке.

Очередь (Queue) - структура данных типа FIFO (First In, First Out).

Отсортированный массив - массив, элементы которого расположены в определенном порядке (возрастание или убывание).

П

Палиндром - последовательность символов, которая читается одинаково слева направо и справа налево.

Подмассив - непрерывная часть массива.

Подмножество - набор элементов, выбранных из большего множества.

Постфиксный обход (Post-order) - обход дерева: сначала дети, затем родитель.

Префиксный обход (Pre-order) - обход дерева: сначала родитель, затем дети.

Приоритетная очередь - структура данных, где элементы извлекаются в порядке приоритета, а не времени добавления.

Пространственная сложность - количество памяти, используемое алгоритмом в зависимости от размера входных данных.

Просеивание (Heapify) - процесс восстановления свойства кучи после изменения элементов.

Р

Рекурсия - техника программирования, при которой функция вызывает саму себя.

Ребро (Edge) - связь между двумя вершинами в графе.

С

Связанный список (Linked List) - структура данных, где элементы связаны указателями.

Скользящее окно - техника работы с подмассивами/подстроками фиксированного или переменного размера.

Сортировка - процесс упорядочивания элементов в определенном порядке.

Стек (Stack) - структура данных типа LIFO (Last In, First Out).

Строка (String) - последовательность символов.

Структура данных - способ организации и хранения данных в памяти компьютера.

Субструктура - часть структуры данных (например, поддерево).

Т

Топологическая сортировка - упорядочивание вершин ориентированного графа так, чтобы для каждого ребра (u, v) вершина u шла перед v.

Транзитивное замыкание - множество всех вершин, достижимых из данной вершины в графе.

Трассировка - процесс отслеживания выполнения алгоритма шаг за шагом.

У

Указатель (Pointer) - переменная, хранящая адрес другой переменной в памяти.

Узел (Node) - элемент структуры данных (дерева, списка, графа).

Утечка памяти - ситуация, когда память выделяется, но не освобождается.

Ф

Фиксированное окно - скользящее окно постоянного размера.

Функция обратного вызова (Callback) - функция, передаваемая в качестве аргумента другой функции.

Х

Хеш-таблица (Hash Table) - структура данных, обеспечивающая быстрый доступ к элементам по ключу.

Хэмминга расстояние - количество позиций, в которых биты двух чисел различаются.

Хеш-функция - функция, преобразующая ключ в индекс массива.

Ц

Цикл - замкнутый путь в графе или списке.

Циклическая сортировка - алгоритм сортировки на месте для массивов с элементами в определенном диапазоне.

Ч

Частота - количество появлений элемента в структуре данных.

Э

Элемент - отдельный объект в структуре данных.

Эффективность алгоритма - соотношение времени выполнения и используемой памяти.

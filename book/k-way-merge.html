K-way Merge (K-way слияние)

Теория

K-way Merge объединяет K отсортированных массивов (списков, потоков) в один отсортированный результат. Это обобщение слияния двух отсортированных массивов.

Ключевая идея: следующий минимальный элемент результата — это минимум среди первых непрочитанных элементов всех K массивов. Min-heap позволяет находить этот минимум за O(log k), храня по одному «текущему» элементу от каждого массива. Извлекли минимум — добавили следующий элемент из того же массива.

Когда применять:

  • нужно слить K отсортированных массивов/списков в один;
  • требуется внешняя сортировка (данные не помещаются в память, лежат в отсортированных файлах);
  • нужно обработать несколько отсортированных потоков и брать глобальный минимум.

Алгоритм

Кладём в кучу первый элемент каждого массива вместе с индексом массива и позицией. Пока куча не пуста: извлекаем минимум в результат и добавляем следующий элемент из того же массива.

import "container/heap"

// Элемент кучи: значение + откуда оно пришло
type Element struct {
    Val      int // значение
    ArrayIdx int // индекс массива
    ElemIdx  int // позиция в этом массиве
}

type MinHeap []Element

func (h MinHeap) Len() int            { return len(h) }
func (h MinHeap) Less(i, j int) bool  { return h[i].Val < h[j].Val }
func (h MinHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x interface{}) { *h = append(*h, x.(Element)) }
func (h *MinHeap) Pop() interface{} {
    old := *h
    n := len(old)
    x := old[n-1]
    *h = old[:n-1]
    return x
}

func mergeKSortedArrays(arrays [][]int) []int {
    h := &MinHeap{}
    heap.Init(h)
    // Первый элемент каждого непустого массива
    for i := range arrays {
        if len(arrays[i]) > 0 {
            heap.Push(h, Element{Val: arrays[i][0], ArrayIdx: i, ElemIdx: 0})
        }
    }

    result := make([]int, 0)
    for h.Len() > 0 {
        minElem := heap.Pop(h).(Element) // глобальный минимум среди непрочитанных
        result = append(result, minElem.Val)

        next := minElem.ElemIdx + 1
        if next < len(arrays[minElem.ArrayIdx]) {
            heap.Push(h, Element{
                Val:      arrays[minElem.ArrayIdx][next],
                ArrayIdx: minElem.ArrayIdx,
                ElemIdx:  next,
            })
        }
    }
    return result
}

Сложность

ПодходВремяПамять
Наивный (минимум из k каждый раз)O(n·k)O(1)
K-way merge с кучейO(n log k)O(k)

Где n — общее число элементов, k — количество массивов. Каждый из n элементов проходит через push/pop кучи размера ≤ k за O(log k).

Типичные ошибки

  1. Не сохранён источник элемента — в куче нужно хранить индекс массива и позицию, иначе непонятно, какой элемент подкладывать следующим.
  2. Добавление пустых массивов на старте — кладите в кучу только первый элемент непустых массивов.
  3. Выход за границу при подкладывании — проверяйте next < len(arrays[idx]) перед push.
  4. Сравнение в Less наоборот — для min-heap это h[i].Val < h[j].Val; знак > даст max-heap и неверный порядок.
  5. Забыли heap.Init — куча, собранная без Init/Push, не поддерживает инвариант.

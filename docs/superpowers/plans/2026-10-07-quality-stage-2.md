## Заметные решения этого плана

Для автора книги: что изменится и что трудно откатить.

1. **«Забыл» не обнуляет карточку:** она придёт завтра, а после «Помню» вернётся на предыдущую ступень (22 дня → завтра → 8 дней → 21), а не пойдёт заново 1 → 3 → 8. Сохранённые карточки работают без переноса.
2. **Дневная порция:** не больше 12 карточек и одной «с кодом» в день, остальные ждут завтра. «Позже» отправляет карточку в конец очереди (карточку с кодом без runner'а — на завтра). Сроки от 8 дней получают случайный сдвиг до ±12 %.
3. **Очередь видна везде:** в верхней панели каждой страницы — «🔁 Сегодня: N», в конце главы — галочка «Глава пройдена». В первый день после обновления придёт всё, что копилось без карточек.
4. **Оценку ставит машина.** Карточка «пакет» — одна функция с чистого листа на странице повторения: зелёные тесты = «Помню», подсказка = «С трудом», «сдаюсь» = «Забыл». У задач в тексте, «объясни сам», «🎯» и смешанной карточку оценивает сам виджет.
5. **Виджет «Реши прямо здесь» по умолчанию гоняет тесты одной функции** — первой нерешённой; пакет считается решённым, как раньше, после зелёного прогона целиком. Новая заготовка открывается без подсказок — они за кнопками; сохранённый код не трогается.
6. **Эталон можно увидеть:** «Сдаюсь — показать эталон» появляется после первого прогона (новый запрос сервера `/api/solution`).
7. **Квиз и смешанная — только по отмеченным в трекере главам** (переключатель «по всем главам» есть; при пустом трекере — объяснение). Квиз — порциями по 10; рекорд «N из 64» перестанет показываться.
8. **Тренажёр:** в заготовках появляются абзацы «Шаблон:», «Также решается:», «Признак:». У `bigo.NextGreaterElement` и `DailyTemperatures` верным ответом станет «Монотонный стек»; эталон `graphs.HasCycleUndirected` переписывается с Union-Find на обход.
9. **Текст глав:** шесть лестниц, «Вспомни» в `tree-bfs` и `backtracking`, разворот в главе о списке, Union-Find в `graphs`; затем «Введение» говорит «ядро на расширение не опирается» без исключений.
10. **Новые ключи в браузере:** `algoProgressAt`, `algoFnSolved`, `algoQuizSeen`, `algoPracticeScope` (в экспорте), `algoToday` (счётчик дня, вне экспорта). Формат старых ключей не меняется.

### Task 3: Повторение — расписание, формат карточки, `sync()` и счётчик на каждой странице

**Files:** Modify `srs.js`, `progress.js` (`cb.onchange`), `quiz.css`; `srs-check.js`, `progress-render-check.js`, `review-render-check.js`; `review.md`; `CLAUDE.md`.

**Interfaces:**
- Produces: `window.ALGO_SRS = { schedule(card, grade, now, rnd) → iv, sync(now) → { cards, created }, report(id, grade, now) → { status, iv }, load() → cards }`. `grade`: `"again" | "hard" | "good"`; `rnd()` ∈ [0, 1), по умолчанию `Math.random`; `created` — id заведённых этим вызовом карточек; `status`: `"graded" | "created" | "early" | "none"`.
- Produces: событие `algo-srs:change` на `document` после записи `algoSRS`; карточка `{ due, iv, ease, reps, meta, seen?, note?, back? }`, `back` — интервал в днях, на который карточка вернётся первым «Помню» после «Забыл»; ключ `algoProgressAt` `{ "<href>": ts }`.

Требования:
1. «Забыл» — шаг назад: срок завтра, `iv = 1`, `ease` −0,2, `reps = 0`, заметка как сейчас; `back` — предыдущая ступень интервала, с которого падали (`back`, если карточка ещё не вернулась, иначе `iv`): до 3 дней включительно → 1, иначе `max(3, round(интервал / ease до штрафа))`.
2. Первое «Помню» после «Забыл»: `iv = back`, `back` снимается; дальше «Помню» растит как обычно (с 3 дней и больше — умножением, с 1 — до 3). Первое «С трудом» после «Забыл» — 1 день, `back` снимается.
3. «Помню» при `reps ≥ 2` растит интервал не меньше чем на день (карточки прежней формулы — `J`, Task 4).
4. Разброс: срок = `now + (iv + сдвиг)` дней, `сдвиг = round(iv · 0.125 · (2·rnd() − 1))`, только при `iv ≥ 8`; `card.iv` остаётся номинальным.
5. `sync()` — на каждой странице при загрузке. Срок новой карточки — от метки события: `ch:` — `algoProgressAt[href]` + день (метки нет — от «сейчас»); `pkg:` — `algoPkgSolved[pkg]` + день; `expl:` — заводится и сразу получает оценку виджета: `schedule(новая, algoExplainDone[key].grade, ts)`; промахи — «сейчас». `progress.js` пишет метку при отметке главы и убирает при снятии.
6. `report(id, grade)`: сначала `sync()`; карточка заведена этим вызовом → `created`; карточки нет → `none`; срок подошёл → оценить (`graded`); не подошёл: «Забыл» применяется, остальное — `early` без изменений.

# Алгоритмические шаблоны для решения задач на собеседованиях

Этот репозиторий содержит подробное изучение 14 основных алгоритмических шаблонов, которые помогут решить большинство задач на технических собеседованиях.

## 📚 Содержание

1. [Sliding Window (Скользящее окно)](./sliding-window.md) - Операции с подмассивами фиксированного размера
2. [Two Pointers (Два указателя)](./two-pointers.md) - Поиск пар элементов в отсортированных массивах
3. [Fast & Slow Pointers (Быстрые и медленные указатели)](./fast-slow-pointers.md) - Обнаружение циклов и поиск середины списка
4. [Merge Intervals (Слияние интервалов)](./merge-intervals.md) - Работа с перекрывающимися интервалами
5. [Cyclic Sort (Циклическая сортировка)](./cyclic-sort.md) - Сортировка массивов с числами от 1 до N
6. [Reverse Linked List (Разворот связанного списка)](./reverse-linked-list.md) - Инвертирование списков на месте
7. [Tree BFS (Обход дерева в ширину)](./tree-bfs.md) - Поуровневый обход деревьев
8. [Tree DFS (Обход дерева в глубину)](./tree-dfs.md) - Рекурсивный обход деревьев
9. [Two Heaps (Две кучи)](./two-heaps.md) - Поддержание медианы и разделение данных
10. [Subsets (Подмножества)](./subsets.md) - Генерация всех подмножеств множества
11. [Modified Binary Search (Модифицированный бинарный поиск)](./modified-binary-search.md) - Вариации бинарного поиска
12. [Top K Elements (Топ K элементов)](./top-k-elements.md) - Поиск K наибольших/наименьших элементов
13. [K-way Merge (K-way слияние)](./k-way-merge.md) - Слияние K отсортированных массивов
14. [Topological Sort (Топологическая сортировка)](./topological-sort.md) - Линейный порядок зависимых элементов

## 🎯 Структура каждого шаблона

Каждый шаблон содержит:
- **README.md** - Подробное теоретическое объяснение с визуализацией, анализом аллокаций, оптимизацией, профилированием и тестированием
- **rust/examples.rs** - Примеры реализации на Rust
- **go/examples.go** - Примеры реализации на Go
- Ссылки на задачи LeetCode для практики

## 🚀 Как использовать

1. Изучите теорию в README.md каждого шаблона
2. Разберите примеры кода на Rust и Go
3. Изучите разделы об аллокациях памяти и оптимизации
4. Практикуйтесь с профилированием и тестированием
5. Решите задачи на LeetCode, указанные в каждом разделе
6. Практикуйтесь, применяя шаблоны к новым задачам

## 💡 Советы по изучению

- Начните с простых шаблонов (Sliding Window, Two Pointers)
- Практикуйтесь на задачах разной сложности
- Понимайте временную и пространственную сложность каждого шаблона
- Изучайте аллокации памяти и оптимизацию для каждого шаблона
- Практикуйтесь с профилированием и тестированием
- Учитесь определять, какой шаблон применить к задаче

## 🔧 Запуск mdbook

Для просмотра книги в формате mdbook:

```bash
# Установка mdbook (если еще не установлен)
cargo install mdbook

# Запуск локального сервера
mdbook serve

# Или сборка статического сайта
mdbook build
```

Книга будет доступна по адресу `http://localhost:3000` при использовании `mdbook serve`.

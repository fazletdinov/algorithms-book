# Шпаргалка и прогресс

Страница для повторения: отметь пройденные главы и держи перед глазами сводную
таблицу «триггер → шаблон → сложность».

## Мой прогресс

**Процент считается по ядру — 23 главам**, а не по всем семидесяти. Расширение и справочник
идут строкой ниже отдельным счётом и процент не разбавляют: цель — дочитать ядро, а не
равномерно проползти оглавление. Что это за уровни и почему их три — в
[«Пути обучения»](./README.md#-путь-обучения). Отмечать можно любую главу: отметки хранятся
для всех одинаково.

> 💡 Отметки сохраняются в браузере (localStorage) и переживут перезагрузку. Кнопка «Экспорт прогресса» складывает в
> один JSON всё: отмеченные главы, решённые задачи, список промахов, рекорд квиза и код,
> который ты писал в виджетах «Реши прямо здесь». «Импорт» вливает этот файл в текущий
> браузер, **не стирая** то, что уже пройдено здесь: отметка главы не снимается, у каждой карточки
> повторений остаётся более свежая оценка (файл старше текущего состояния ничего не откатит), а
> значение из файла, которое не читается как данные того же вида, не затрёт здешние карты и
> списки — так прогресс переезжает на другую машину и переживает чистку кэша.

## Повторить промахи

Задача из любой главы попадает в список автоматически, когда ответ не сошёлся, и уходит из
него, как только ты её решишь. Сам список и очередь интервальных повторений — на странице
[«Повторение: что сегодня»](review.md).

## Сводная таблица шаблонов

Первым делом — ограничение `n` в условии: `n ≤ 20` разрешает перебор `2ⁿ`, `n ≤ 10⁵` требует
`O(n log n)` или быстрее. Полная таблица — [«размер входа → сложность»](big-o.md#размер-входа-подсказывает-сложность).

Ключевой навык — по **триггерам в условии** мгновенно выбрать подход. Потренировать выбор
можно в [тренажёре распознавания шаблонов](quiz.md).

| Шаблон | Триггеры в условии | Сложность | Ключевая идея |
|--------|--------------------|-----------|---------------|
| [Sliding Window](sliding-window.md) | подмассив/подстрока, «самый длинный/короткий при условии» | O(n) | окно: +новый −старый |
| [Prefix Sums](prefix-sums.md) | сумма отрезка много раз, «сколько подмассивов с суммой k», прибавка к диапазону | O(n) + O(1) на запрос | `prefix[r+1] − prefix[l]`; map прошлых префиксов |
| [Two Pointers](two-pointers.md) | отсортированный массив, пары/тройки, палиндром | O(n) | два указателя навстречу/в одну сторону |
| [Monotonic Stack](monotonic-stack.md) | ближайший больший/меньший, скобки и вложенность, гистограмма | O(n) аморт. | стек индексов: новый снимает тех, для кого он ответ |
| [Fast & Slow Pointers](fast-slow-pointers.md) | цикл в списке, середина, O(1) памяти | O(n) | указатели ×1 и ×2 (Флойд) |
| [Merge Intervals](merge-intervals.md) | перекрывающиеся интервалы | O(n log n) | сортировка по началу + слияние |
| [Cyclic Sort](cyclic-sort.md) | числа 1..n, пропавшие/дубликаты, O(1) памяти | O(n) | число v → индекс v−1 |
| [Modified Binary Search](modified-binary-search.md) | отсортировано (м.б. повёрнуто), граница/вставка | O(log n) | деление пополам по предикату |
| [Bit Manipulation](bit-manipulation.md) | пары/маски, «единственное число» | O(n) | XOR, сдвиги, маски |
| [Reverse Linked List](reverse-linked-list.md) | разворот списка/подсписка на месте | O(n), O(1) | prev / curr / next |
| [Tree BFS](tree-bfs.md) | по уровням, кратчайший по рёбрам | O(n) | очередь, уровень за уровнем |
| [Tree DFS](tree-dfs.md) | пути, валидация, свойства поддеревьев, LCA | O(n) | рекурсия pre/in/post |
| [Две кучи](two-heaps.md) | медиана потока, разделение на половины | O(log n)/вставка | max-heap + min-heap |
| [Топ K элементов](top-k-elements.md) | K наибольших/наименьших, K-й по величине | O(n log k) | heap размера K |
| [K-way Merge](k-way-merge.md) | слить K отсортированных источников | O(n log k) | min-heap из голов |
| [Subsets](subsets.md) / [Backtracking](backtracking.md) | «все комбинации/перестановки» | экспонента | выбор → рекурсия → откат |
| [Graphs (обход)](graphs.md) | обход, связность, компоненты, цикл (неориент.) | O(V+E) | visited + очередь/рекурсия |
| [Union-Find](union-find-structure.md) | динамическая связность, цикл при добавлении рёбер (неориент.) | ~O(1)/опер. | сжатие пути + ранг |
| [Topological Sort](topological-sort.md) | зависимости/порядок, DAG | O(V+E) | Кан: убираем вершины с in-degree 0 |
| BFS / [Dijkstra](grids-and-shortest-paths.md) | кратчайший путь (1 / неотриц. веса) | O(V+E) / O((V+E)log V) | очередь / приоритетная очередь |
| [Bellman–Ford / A\*/ MST](advanced-graph-algorithms.md) | отрицат. веса / эвристика / остов | O(V·E) / — / O(E log E) | релаксация / f=g+h / жадно+DSU |
| [SCC / мосты / точки сочленения](graph-connectivity.md) | циклы зависимостей, критичное ребро/узел, «без чего граф распадётся» | O(V+E) | DFS: порядок завершения / low-link |
| [Greedy](greedy.md) | макс/мин с доказуемым локальным выбором | O(n log n) | локально оптимальный шаг |
| [Dynamic Programming](dynamic-programming.md) | мин/макс/счёт + перекрыв. подзадачи | завис. от состояний | состояние + переход + мемоизация |
| [Строковые алгоритмы](string-algorithms.md) | поиск подстроки/образца | O(n+m) | префикс-функция (KMP) / rolling hash |
| [Trie](trie-structure.md) | префикс, автодополнение, словарь | O(длины) | префиксное дерево |
| [Segment Tree](segment-tree-structure.md) / [Fenwick](fenwick-tree-structure.md) | сумма/мин на диапазоне + обновления | O(log n) | дерево агрегатов |
| [Комбинации паттернов](pattern-combinations.md) | задача = связка 2–3 паттернов (LRU, Word Ladder…) | зависит от связки | один даёт структуру, другой — порядок |

## Как готовиться по этой странице

1. Изучил главу — отметь её: галочкой «Глава пройдена» в конце самой главы или здесь, в трекере
   (это одна и та же отметка).
2. Раз в несколько дней пробегай таблицу: по триггеру вспоминай идею и сложность.
3. Закрепляй в [тренажёре распознавания](quiz.md) и в Go-тренажёре (каталог `exercises/`).

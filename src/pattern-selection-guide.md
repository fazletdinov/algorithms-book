# Руководство по выбору алгоритмического шаблона

Это руководство поможет вам быстро определить, какой алгоритмический шаблон использовать для решения конкретной задачи.

## Decision Tree (Дерево решений)

```
Начало
  │
  ├─ Работа с массивами/строками?
  │   │
  │   ├─ Нужен подмассив/подстрока фиксированного размера?
  │   │   └─ → Sliding Window
  │   │
  │   ├─ Массив отсортирован? Нужно найти пару/тройку?
  │   │   └─ → Two Pointers
  │   │
  │   ├─ Массив с числами в диапазоне [1, n]?
  │   │   └─ → Cyclic Sort
  │   │
  │   └─ Массив отсортирован? Нужен поиск?
  │       └─ → Modified Binary Search
  │
  ├─ Работа со связанными списками?
  │   │
  │   ├─ Нужно обнаружить цикл или найти середину?
  │   │   └─ → Fast & Slow Pointers
  │   │
  │   └─ Нужно развернуть список?
  │       └─ → Reverse Linked List
  │
  ├─ Работа с деревьями?
  │   │
  │   ├─ Нужен обход по уровням?
  │   │   └─ → Tree BFS
  │   │
  │   └─ Нужен обход в глубину?
  │       └─ → Tree DFS
  │
  ├─ Работа с интервалами?
  │   └─ → Merge Intervals
  │
  ├─ Нужно найти K наибольших/наименьших элементов?
  │   └─ → Top K Elements
  │
  ├─ Нужно поддерживать медиану?
  │   └─ → Two Heaps
  │
  ├─ Нужно слить K отсортированных массивов/списков?
  │   └─ → K-way Merge
  │
  ├─ Нужно сгенерировать все подмножества/комбинации?
  │   └─ → Subsets
  │
  └─ Работа с графом и зависимостями?
      └─ → Topological Sort
```

## Детальное описание по типам задач

### Работа с массивами и строками

#### Sliding Window
**Используйте, когда:**
- Нужно найти подмассив/подстроку определенного размера
- Нужно найти подмассив/подстроку, удовлетворяющую условию
- Задача связана с "окном" фиксированного или переменного размера

**Примеры задач:**
- Найти максимальную сумму подмассива размера k
- Найти минимальную подстроку, содержащую все символы
- Найти все анаграммы в строке

#### Two Pointers
**Используйте, когда:**
- Массив отсортирован
- Нужно найти пару/тройку элементов с определенным свойством
- Нужно удалить дубликаты из отсортированного массива
- Нужно проверить палиндром

**Примеры задач:**
- Найти два числа с заданной суммой
- Удалить дубликаты из отсортированного массива
- Проверить, является ли строка палиндромом

#### Cyclic Sort
**Используйте, когда:**
- Массив содержит числа в диапазоне [1, n] или [0, n-1]
- Нужно найти отсутствующие числа
- Нужно найти дубликаты
- Можно использовать индексы как хеш-таблицу

**Примеры задач:**
- Найти отсутствующее число
- Найти все дубликаты
- Найти первое отсутствующее положительное число

#### Modified Binary Search
**Используйте, когда:**
- Массив отсортирован (или частично отсортирован)
- Нужно найти элемент или границу
- Нужно найти в повернутом отсортированном массиве
- Нужно найти в 2D отсортированной матрице

**Примеры задач:**
- Найти элемент в отсортированном массиве
- Найти первую/последнюю позицию элемента
- Найти минимум в повернутом массиве

### Работа со связанными списками

#### Fast & Slow Pointers
**Используйте, когда:**
- Нужно обнаружить цикл в списке
- Нужно найти середину списка
- Нужно найти K-й элемент с конца
- Нужно проверить палиндром в списке

**Примеры задач:**
- Обнаружить цикл в связанном списке
- Найти середину связанного списка
- Проверить, является ли список палиндромом

#### Reverse Linked List
**Используйте, когда:**
- Нужно развернуть весь список
- Нужно развернуть часть списка
- Нужно развернуть список группами

**Примеры задач:**
- Развернуть связанный список
- Развернуть список между позициями m и n
- Развернуть узлы группами по k

### Работа с деревьями

#### Tree BFS
**Используйте, когда:**
- Нужен обход дерева по уровням
- Нужно найти кратчайший путь
- Нужно обработать все узлы на одном уровне перед переходом к следующему

**Примеры задач:**
- Обход дерева по уровням
- Найти среднее значение каждого уровня
- Найти вид дерева справа

#### Tree DFS
**Используйте, когда:**
- Нужен обход в глубину (pre-order, in-order, post-order)
- Нужно валидировать дерево
- Нужно построить дерево из обхода
- Нужно найти путь с определенным свойством

**Примеры задач:**
- Валидация бинарного дерева поиска
- Найти максимальную сумму пути
- Построить дерево из pre-order и in-order обхода

### Работа с интервалами

#### Merge Intervals
**Используйте, когда:**
- Работаете с интервалами
- Нужно объединить перекрывающиеся интервалы
- Нужно вставить новый интервал
- Нужно найти пересечение интервалов

**Примеры задач:**
- Объединить перекрывающиеся интервалы
- Вставить интервал
- Найти пересечение интервалов

### Продвинутые структуры данных

#### Top K Elements
**Используйте, когда:**
- Нужно найти K наибольших элементов
- Нужно найти K наименьших элементов
- Нужно найти K наиболее частых элементов
- Нужно найти K ближайших точек

**Примеры задач:**
- Найти K-й наибольший элемент
- Найти топ K частых элементов
- Найти K ближайших точек к началу координат

#### Two Heaps
**Используйте, когда:**
- Нужно поддерживать медиану потока данных
- Нужно балансировать две части данных
- Нужно быстро получать минимум и максимум

**Примеры задач:**
- Медиана из потока данных
- Медиана скользящего окна
- Балансировка двух множеств

#### K-way Merge
**Используйте, когда:**
- Нужно слить K отсортированных массивов
- Нужно слить K отсортированных списков
- Нужно найти K-й наименьший элемент в K отсортированных структурах

**Примеры задач:**
- Слить K отсортированных списков
- Найти K-й наименьший элемент в отсортированной матрице
- Найти K пар с наименьшими суммами

### Комбинаторика и графы

#### Subsets
**Используйте, когда:**
- Нужно сгенерировать все подмножества
- Нужно сгенерировать все комбинации
- Нужно сгенерировать все перестановки
- Задача связана с backtracking

**Примеры задач:**
- Найти все подмножества
- Найти все комбинации суммы
- Найти все перестановки

#### Topological Sort
**Используйте, когда:**
- Работаете с ориентированным графом
- Есть зависимости между элементами
- Нужно упорядочить элементы с учетом зависимостей
- Нужно определить, можно ли выполнить все задачи

**Примеры задач:**
- Расписание курсов
- Словарь инопланетян
- Реконструкция последовательности

## Комбинирование шаблонов

Многие задачи требуют комбинирования нескольких шаблонов:

### Sliding Window + Heap
- Поиск максимума/минимума в скользящем окне
- Пример: [Sliding Window Maximum](https://leetcode.com/problems/sliding-window-maximum/)

### DFS + Backtracking
- Генерация подмножеств и перестановок
- Пример: [N-Queens](https://leetcode.com/problems/n-queens/)

### BFS + Graph
- Топологическая сортировка
- Пример: [Course Schedule](https://leetcode.com/problems/course-schedule/)

### Two Pointers + Binary Search
- Поиск тройки с заданной суммой
- Пример: [3Sum](https://leetcode.com/problems/3sum/)

## Чеклист для выбора шаблона

1. **Проанализируйте входные данные:**
   - Какой тип данных? (массив, список, дерево, граф)
   - Отсортированы ли данные?
   - Какой размер данных?

2. **Определите цель задачи:**
   - Поиск элемента?
   - Поиск подмассива/подстроки?
   - Генерация всех возможных вариантов?
   - Обход структуры данных?

3. **Учтите ограничения:**
   - Требования к временной сложности
   - Требования к пространственной сложности
   - Можно ли изменять исходные данные?

4. **Проверьте типичные паттерны:**
   - Похожа ли задача на изученные примеры?
   - Какие структуры данных используются?
   - Есть ли зависимости между элементами?

## Полезные советы

1. **Начните с простого:** Если задача кажется сложной, попробуйте упростить ее и найти базовый шаблон.

2. **Используйте визуализацию:** Нарисуйте примеры входных и выходных данных, это поможет понять паттерн.

3. **Анализируйте примеры:** Изучите примеры задач для каждого шаблона, чтобы понять типичные применения.

4. **Практикуйтесь:** Решайте задачи на LeetCode, чтобы развить интуицию для выбора правильного шаблона.

5. **Не бойтесь экспериментировать:** Если один шаблон не работает, попробуйте другой или комбинацию шаблонов.

## Заключение

Выбор правильного алгоритмического шаблона - это навык, который развивается с практикой. Используйте это руководство как отправную точку, но помните, что многие задачи могут решаться несколькими способами. Главное - понять суть задачи и выбрать наиболее подходящий подход.
